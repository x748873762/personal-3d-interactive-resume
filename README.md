# 个人3D交互简历网站

一个以纸张、便签与原创几何角色为主题的 React 网站模板。所有角色、叙事、能力描述与作品均为虚构示例，不代表真实人物、工作履历或项目成果。

**公开展示通用模板代码与演示，项目自身许可证尚未指定（UNLICENSED）。**

在线体验：[个人3D交互简历网站](https://x748873762.github.io/personal-3d-interactive-resume/)。

## 本地运行

需要 Node.js 22.12+（本次使用 24.17.0）及 pnpm 11（本次使用 11.19.0）。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开 `http://127.0.0.1:5187/`。开发服务只监听本机。无后端、无账户、无 API key、无环境文件。

```sh
pnpm build
pnpm preview
```

生产预览地址为 `http://127.0.0.1:4187/`。构建使用相对资源路径，便于后续在子路径中使用；线上使用独立 gh-pages 分支部署构建产物。

## 可以体验什么

- 右上角街机按钮切换红黑／暖灰主题，浏览器记住选择；禁用本地存储时仍可切换。
- 桌面几何角色有实时光照、视线跟随与滚动镜头联动。五张便签可悬停、键盘聚焦、点击直达叙事；当前便签提亮。
- 五段叙事均可翻到关联作品，再返回第一页。
- 桌面画廊支持滚轮、方向按钮与左右键，计数跟随；滚到端点后可继续纵向滚动。窄屏改为纵向排列。
- 点击作品打开原生预览弹窗；关闭按钮、Escape 与背景均可关闭，并恢复打开前焦点。
- 能力便签与页尾入口有纸边和悬停反馈，提供同等键盘反馈。
- 窄屏、减少动态或 WebGL 不可用时显示原创 CSS 静态角色；减少动态时取消非必要动画。

## 内容与结构

| 文件 | 用途 |
| --- | --- |
| `src/content.js` | 五段虚构叙事、作品与能力标签 |
| `src/App.jsx` | 页面顺序、主题、翻页、导航、预览 |
| `src/components/Character.jsx` | 基础几何角色、镜头、回退与资源释放 |
| `src/components/Gallery.jsx` | 抽象图形、横向画廊及控制 |
| `src/styles.css` | 色彩变量、纸张细节、动效与窄屏布局 |

图片、图标字体、模型、纹理与字体文件均无需下载。角色由 Three.js 基础体组成；图形由 CSS 绘制；字体来自操作系统。

## 验证

```sh
pnpm exec playwright install chromium
pnpm test
pnpm build
pnpm check:privacy
```

如已安装 Chrome，也可使用 `PW_CHANNEL=chrome pnpm test`。测试覆盖主题记忆、导航、翻页、画廊、预览焦点、窄屏、减少动态、WebGL 回退与网络边界。截图和测试输出保存至系统临时目录，不进入源码包。

隐私检查按明确清单检查源码与构建产物。自动扫描不是个人资料审查或授权判断的替代品；更换内容后需要重新运行检查并人工复核。

## 本地发布候选包

```sh
pnpm build
pnpm check:privacy
pnpm prepare:release
```

脚本只将 `scripts/release-files.mjs` 中的文件写入新的 `release-candidate/`，生成 SHA-256 清单。不包含依赖目录、构建文件、测试截图或本地管理文档。目标目录已存在时拒绝覆盖；需要重做时，先把旧候选目录改名留存。候选包可在独立目录重新安装运行。

此命令只准备本地候选文件，不执行 Git、不访问远端、不部署。项目线上版本由维护者单独发布至 gh-pages 分支；main 保留通用源码。
